The silent-black-25s.mp4 playback fixture is from AndroidX Media's test suite:
https://github.com/androidx/media/blob/release/libraries/test_data/src/test/assets/media/mp4/silent-black-25s.mp4

It is used only by instrumentation tests, not packaged in the release APK.

`native-tracks/` is a 90-second synthetic HLS fixture generated by
`tools/create_native_test_media.sh`: two test-pattern video resolutions,
separate 440/660 Hz AAC tracks labeled English/Spanish, and a WebVTT test cue.
It contains no provider/movie content. The master and caption playlists are
maintained alongside the generated segments. It is androidTest-only.
